ATELIER OG DIGITAL MENU — CLIENT CONFIGURATION

Set the GST rate separately for every client in index.html:

window.ATELIER_MENU_CONFIG = {
  client: "daily-table",
  name: "The Daily Table",
  slug: "daily-table",
  basePath: "/atelier-og-digital-menu/",
  whatsapp: "919999999999",
  location: "The Daily Table",
  gstRate: 5
};

Examples:
gstRate: 3   = 3% GST
gstRate: 5   = 5% GST
gstRate: 12  = 12% GST
gstRate: 18  = 18% GST

The selected rate is shown in the order summary and included in the WhatsApp order message.

IMPORTANT:
This is a website configuration feature, not tax advice. Set the rate according to the client's applicable tax treatment.
